Thiết Lập Database & Backend

Ứng dụng hiện tại đang hoạt động ngoại tuyến, đồng bộ hóa hoàn toàn với HTML5 LocalStorage. Để nâng cấp ứng dụng lên hệ thống mạng dùng cho nhiều thiết bị, bạn hãy thực hiện theo hướng dẫn cài đặt Backend gọn nhẹ dưới đây:

1. Khởi tạo Bảng trong Supabase SQL Editor

Hãy sao chép và thực thi đoạn mã SQL bên dưới trong bảng điều khiển SQL Editor của Supabase để khởi tạo bảng dữ liệu từ vựng và bảng quản lý SRS:

-- 1. Bảng lưu trữ từ vựng (Vocabulary)
CREATE TABLE vocabulary (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    english_word VARCHAR(255) NOT NULL,
    ipa VARCHAR(255),
    part_of_speech VARCHAR(50),
    vietnamese_meaning VARCHAR(255) NOT NULL,
    phonetic_cue VARCHAR(255) NOT NULL,
    surreal_story TEXT NOT NULL,
    image_url TEXT NOT NULL,
    audio_url TEXT,
    topic VARCHAR(50) DEFAULT 'work',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 2. Bảng theo dõi tiến trình ôn tập SRS
CREATE TABLE srs_progress (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    vocab_id UUID REFERENCES vocabulary(id) ON DELETE CASCADE,
    current_level INT DEFAULT 0,
    interval INT DEFAULT 0,
    ease_factor DECIMAL DEFAULT 2.5,
    next_review_date TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
    last_reviewed TIMESTAMP WITH TIME ZONE,
    UNIQUE(vocab_id)
);

2. Tích hợp Supabase Client vào Frontend

Thêm thư viện CDN Supabase vào thẻ <head> của trang web và kết nối bằng đoạn code JS:

<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
<script>
  const supabase = supabase.createClient('YOUR_SUPABASE_URL', 'YOUR_SUPABASE_ANON_KEY');

  // Hàm tải dữ liệu từ Supabase thay thế LocalStorage
  async function loadVocabularyFromDB() {
    const { data, error } = await supabase.from('vocabulary').select('*');
    if (error) console.error("Lỗi:", error);
    return data;
  }
</script>

1. Cấu trúc Firestore Database

Khởi tạo 2 Collection độc lập trong Cloud Firestore với cấu trúc phân cấp:

// Collection "vocabulary"
document_id: "auto-generated" {
  english_word: "Accuse",
  ipa: "/ə'kjuːz/",
  part_of_speech: "v",
  vietnamese_meaning: "Buộc tội",
  phonetic_cue: "ai cứu",
  surreal_story: "Tôi xin mọi người, ai cứu con tôi bị buộc tội oan!",
  image_url: "https://...",
  topic: "work"
}

// Collection "srs_progress"
document_id: "auto-generated" {
  vocab_id: "reference_to_vocabulary_doc",
  current_level: 0,
  interval: 0,
  ease_factor: 2.5,
  next_review_date: Timestamp,
  last_reviewed: Timestamp
}

2. Tích hợp SDK Firebase vào Frontend

<script type="module">
  import { initializeApp } from "https://www.gstatic.com/firebasejs/10.1.0/firebase-app.js";
  import { getFirestore, collection, addDoc, getDocs } from "https://www.gstatic.com/firebasejs/10.1.0/firebase-firestore.js";

  const firebaseConfig = {
    apiKey: "YOUR_API_KEY",
    projectId: "YOUR_PROJECT_ID",
    databaseURL: "YOUR_DATABASE_URL"
  };

  const app = initializeApp(firebaseConfig);
  const db = getFirestore(app);
</script>
